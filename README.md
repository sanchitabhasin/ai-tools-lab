# AI Tools Lab

A collection of Python utilities and algorithms built as part of the AI Tools and Applications Lab, exploring AI-assisted coding workflows with GitHub Copilot and Claude.

## Project Description

This repository contains sorting algorithms and utility functions developed using AI-assisted development tools. It demonstrates a professional Git workflow including feature branches, pull requests, and AI-assisted code generation, documentation, and review.

## Installation

Clone the repository:

git clone https://github.com/sanchitabhasin/ai-tools-lab.git
cd ai-tools-lab

No external dependencies are required — the project uses Python's standard library only.

## Usage

Run hello.py for a basic greeting:

python hello.py

Run sorting.py to see bubble sort in action:

python sorting.py

Run utils.py to see the utility functions in action:

python utils.py

Example usage in code:

from utils import is_palindrome, count_words, celsius_to_fahrenheit

is_palindrome("Madam")           # True
count_words("This is a test")    # 4
celsius_to_fahrenheit(100)       # 212.0
